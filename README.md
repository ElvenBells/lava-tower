# Lava Tower — Babylon.js Modular Edition

3D-рогалик на выживание и вертикальный подъём по башне на движке **Babylon.js**.
Бегите вверх по 12 этажам трёх уникальных башен (Пепельная, Ледяная, Башня Пустоты), пока снизу поднимается лава, метель или бездна. Оружие атакует автоматически, а на этажах 4, 8 и 12 путь преграждают уникальные боссы.

## Архитектура и структура модулей (Babylon.js Standards)

Проект разделён на независимые логические слои в соответствии со стандартами разработки браузерных 3D-игр на движке **Babylon.js**:

```text
lava-tower-babylon/
├── index.html                        # Точка входа HTML и разметка HUD/оверлеев
├── css/
│   └── styles.css                    # Стили интерфейса, меню, HUD и полосы здоровья босса
├── vendor/
│   └── babylon.min.js                # Автономный WebGL2/WebGL1 рантайм Babylon.js
└── src/
    ├── utils/
    │   └── math-and-rng.js           # Математические утилиты, детерминированный ГСЧ, обёртка localStorage
    ├── audio/
    │   └── sound-engine.js           # Процедурный звуковой синтезатор (Web Audio API) с лимитером голосов
    ├── config/
    │   └── game-data.js              # Конфигурация и баланс: оружие, реликвии, тома, мобы, боссы, башни, кузница
    ├── graphics/
    │   ├── scene-setup.js            # Инициализация BABYLON.Engine, BABYLON.Scene, FreeCamera, света, тумана и ACES
    │   └── procedural-textures.js    # Процедурная генерация текстур на базе BABYLON.DynamicTexture
    ├── models/
    │   ├── geometry-utils.js         # Генераторы BABYLON.VertexData, StandardMaterial, Thin Instances, слияние мешей
    │   ├── player-model.js           # Скелетный риг героя «Угленосец», 3D-модели оружия, томов, реликвий и окружения
    │   ├── enemy-models.js           # 12 уникальных 3D-моделей мобов (по 4 роли для каждой из 3 башен)
    │   ├── boss-models.js            # 9 уникальных 3D-моделей боссов (по 3 босса для каждой из 3 башен)
    │   └── mob-factory.js            # Фабрика и объектный пул (MobFactory) мешей мобов и боссов
    ├── effects/
    │   └── particles-and-fx.js       # Пул молний, ударные кольца, гейзеры, 3D-снаряды, клинки, лут и частицы
    ├── world/
    │   └── tower-generator.js        # Генератор 12 этажей башни, пространственная сетка коллизий, сундуки, алтари, печати
    ├── game/
    │   ├── combat-and-loot.js        # Боевая система, пространственная сетка врагов, спавн волн, элиты, лут и события
    │   ├── boss-ai.js                # Машины состояний ИИ, опасные зоны и процедурная анимация поз всех 9 боссов
    │   ├── physics-and-step.js       # Обработка ввода (WASD + мышь), инициализация забега и шаг физики (60 Гц)
    │   └── renderer.js               # Кадровый рендеринг сцены Babylon.js, LOD-анимация, синхронизация Thin Instances и HUD
    ├── ui/
    │   └── menus-and-hud.js          # Главное меню, выбор башни/героя, кузница, карточки улучшений, пакты и таблица рекордов
    └── main.js                       # Прогрев шейдеров, адаптивный контроль разрешения (HardwareScalingLevel) и игровой цикл
```

## Запуск игры

1. **Прямой запуск:** откройте файл `index.html` в любом современном браузере (Chrome, Edge, Firefox, Safari). Все скрипты подключены локально и не требуют сборщика или интернет-соединения.
2. **Через локальный веб-сервер (рекомендуется для разработки):**
   ```bash
   python3 -m http.server 8000
   ```
   Затем откройте `http://localhost:8000` в браузере.
