# Lava Tower — Babylon.js Modular Edition (Upgraded 3D Towers, GLSL Shaders, Audio & Storms)

3D-рогалик на выживание и вертикальный подъём по башне на движке **Babylon.js**.
Бегите вверх по 12 этажам трёх уникальных башен (Пепельная, Ледяная, Башня Пустоты), пока снизу поднимается лава, метель или бездна. Оружие атакует автоматически, а на этажах 4, 8 и 12 путь преграждают уникальные боссы.

## Обновлённый визуал, шейдеры, аудио и механики бурь

1. **Пепельная башня («Великий Горн»)**:
   - **Зафиксированные базовые параметры**: Интенсивность свечения (Bloom) = `0.3`, Порог свечения (Threshold) = `0.14`, Термическое искажение воздуха = `0.039`, Скорость течения магмы = `2.25`, Плотность пепельного тумана = `0.065`.
   - **Визуал и механики**: Детализированные базальтовые стены и пол с обугленными до черноты участками (`stoneNoise3D`) и лавовыми трещинами; 3D-потоки стекающей по стенам лавы (сплайновые ручьи с переменным сечением, коркой шлака, ответвлениями и скользящими вниз 3D-сгустками лавы, шейдер `flowingLava`); органические 3D-лужи лавы на полу (`lavaPuddle`), наносящие небольшой постоянный урон игроку при наступании; стекающая и капающая со ступеней лава с расходящимися кругами в небольших лужицах под ними.
2. **Ледяная башня («Обитель Первозданного Холода»)**:
   - **Зафиксированные базовые параметры**: Кристаллический ореол (Bloom) = `0.00`, Эмиссия трещин льда = `1.95`, Плотность снежной взвеси = `0.004`, Скорость бездонной метели = `0.5`.
   - **Визуал и механики**: Вмёрзшие в толщу ледяных стен силуэты странников и воинов за прозрачными линзами льда; сплошной глубокий лёд пола с яркими светящимися трещинами внутри (`#88ddff`) и стелющимся морозным паром (`creepingFog`); морозная корка и свисающие со ступеней и обрывов каскады сосулек; 3-слойная воронка бездонной метели (`blizzardVortex`); сохранён эффект проскальзывания.
3. **Башня Пустоты («Граница Ничего»)**:
   - **Зафиксированные базовые параметры**: Сияние рун (Bloom) = `0.30`, Искажение реальности (RGB Shift) = `0.0046`, Аномалия гравитации = `1.4`, Порог растворения ступеней = `0.39`.
   - **Визуал и механики**: Чёрный обсидиановый пол (`#06040a`) с редкими сверкающими вкраплениями «звёздной пыли» (`obsidianFloor`); стены и колонны с асинхронно пульсирующими R/G/B рунами (`wallRunes`); визуально «растворившиеся» ступени (`stairDissolve` 3D Simplex Noise) в окружении эфирного тумана (`voidMist`), по которым игрок может полноценно ходить; полупрозрачные ленты абсолютной тьмы, сложенное небо (`skyRift`), парящие осколки, бездна с параллаксом (`abyss`) и биолюминесцентный планктон (`plankton`); сохранена низкая гравитация.
4. **Аудиосистема (Web Audio API)**:
   - Перенесены процедурные фоновые эмбиент-синтезаторы из всех трёх 3D-сцен (низкий гул горна Пепельной башни, завывающий буран Ледяной башни, эфирный гул Башни Пустоты), которые непрерывно звучат фоном под боевыми звуковыми эффектами (атака, получение урона, ожог в лавовой луже, прыжки, сбор лута, раскаты бури).
5. **Периодические «Бури» в башнях**:
   - Раз в некоторое время в башне начинается короткая буря, усложняющая видимость и меняющая параметры среды:
     - **Пепельная буря**: Bloom -> `2.2`, Термическое искажение воздуха -> `0.073`, Плотность пепельного тумана -> `0.03`.
     - **Ледяной буран**: Скорость бездонной метели -> `0.9`, Плотность снежной взвеси -> `0.024`, Кристаллический ореол (Bloom) -> `0.08`.
     - **Шторм Пустоты**: Сияние рун (Bloom) -> `2.15`, Искажение реальности (RGB Shift) -> `0.0080`, Порог растворения ступеней -> `0.65`, плюс дополнительное ослабление гравитации для ещё более долгого приземления после прыжка.

## Архитектура и структура модулей

```text
lava-tower-babylon/
├── index.html                        # Точка входа HTML и разметка HUD/оверлеев
├── css/
│   └── styles.css                    # Стили интерфейса, меню, HUD и полосы здоровья босса
├── vendor/
│   └── babylon.min.js                # Автономный WebGL2/WebGL1 рантайм Babylon.js (с ShaderMaterial и FBO PostProcess)
└── src/
    ├── utils/
    │   └── math-and-rng.js           # Математические утилиты, детерминированный ГСЧ, обёртка localStorage
    ├── audio/
    │   └── sound-engine.js           # Фоновые эмбиент-синтезаторы 3 башен + боевые SFX (Web Audio API)
    ├── config/
    │   └── game-data.js              # Конфигурация, зафиксированные VFX-параметры и параметры бурь 3 башен
    ├── graphics/
    │   ├── scene-setup.js            # Инициализация BABYLON.Engine, GLSL ShadersStore, CatmullRomCurve3 и пост-обработки
    │   └── procedural-textures.js    # Процедурные текстуры базальта/копоти, глубокого льда, силуэтов, R/G/B рун и звёздной пыли
    ├── models/
    │   ├── geometry-utils.js         # Генераторы геометрии, нормалей, слияние мешей
    │   ├── player-model.js           # Риг героя «Угленосец», море магмы (lavaSea), метель (blizzardVortex), бездна (abyss), стены (wallRunes)
    │   ├── enemy-models.js           # 12 уникальных 3D-моделей мобов (по 4 роли для каждой из 3 башен)
    │   ├── boss-models.js            # 9 уникальных 3D-моделей боссов (по 3 босса для каждой из 3 башен)
    │   └── mob-factory.js            # Фабрика и объектный пул (MobFactory) мешей мобов и боссов
    ├── effects/
    │   └── particles-and-fx.js       # Пул молний, ударные кольца, гейзеры, 3D-снаряды, клинки, лут и частицы
    ├── world/
    │   └── tower-generator.js        # Генератор 12 этажей, 3D-потоки и лужи лавы, капли со ступеней, сосульки, растворяющиеся ступени Пустоты
    ├── game/
    │   ├── combat-and-loot.js        # Боевая система, пространственная сетка врагов, спавн волн, элиты, лут и события
    │   ├── boss-ai.js                # Машины состояний ИИ, опасные зоны и процедурная анимация поз всех 9 боссов
    │   ├── physics-and-step.js       # Шаг физики (60 Гц), урон от лавовых луж и система периодических «Бурь»
    │   └── renderer.js               # Кадровый рендеринг сцены Babylon.js, LOD-анимация и HUD
    ├── ui/
    │   └── menus-and-hud.js          # Главное меню, управление звуком, кузница, карточки улучшений, пакты и таблица рекордов
    └── main.js                       # Прогрев шейдеров, адаптивный контроль разрешения и главный игровой цикл
```

## Запуск игры

1. **Прямой запуск:** откройте файл `index.html` в любом современном браузере (Chrome, Edge, Firefox, Safari). Все скрипты подключены локально и не требуют сборщика или интернет-соединения.
2. **Через локальный веб-сервер (рекомендуется для разработки):**
   ```bash
   python3 -m http.server 8000
   ```
   Затем откройте `http://localhost:8000` в браузере.
